# 起点：前端底子扎实，Python 刚起步，Agent 有使用直觉但无机制认知

学习者是 TypeScript + React/Vue 前端开发者，用过 Node，工程概念（模块、异步、类型、包管理）齐备。Python 处于起步阶段：`hello.py` 中已独立写出 `sum(range(1,101))` 与「列表遍历 + `if/else` 分支」，说明 `for` / `if` / `list` / `range` 可用。日常使用 Claude Code / Cursor，因此对 Agent 的**行为**有直觉，但尚未接触其**内部机制**。

## Implications

- **不要从零讲编程概念。** 函数、循环、条件、异步、模块他都有，只缺 Python 写法。每个新语法给出 TS 对照即可，省下的工作记忆用来装真正的新知识。这是本工作区所有课程的基本策略。
- **不需要「AI 是什么」的铺垫。** 可以直接从「Agent 内部是一个循环」这种机制层切入，跳过整个科普层。
- **终点是独立交付**（见 [[MISSION.md]]），因此每节课都要落在可运行、可留存的代码上，而非抛弃式练习。
- **每天 20–30 分钟**是硬约束，单节课必须自洽且可一口气完成。

## 待验证

Python 的**行为**差异（而非语法差异）是这类迁移者的主要风险区：空列表 / 空字典为假值、可变默认参数、`is` 与 `==`、`/` 与 `//`、无块级作用域。已写入 `reference/python-for-ts-devs.html` 的「七个坑」，但尚无证据表明他已内化，需在后续课程中反复回考。
