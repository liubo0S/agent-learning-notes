## 一次由他触发的教材修正

第 2 课初稿写的是 `resp.content[0].text`。他用 `kimi-k3`（思考型模型）跑自检时撞上
`AttributeError: 'ThinkingBlock' object has no attribute 'text'`。

**根因是我的简化写法有错**：该写法只在非思考模型上偶然成立。已修正教材，并在 [[NOTES.md]] 立了规矩：教材中禁止出现 `content[0].text`。

**教学价值高于修正本身**：这给了一个真实的、由他自己触发的反例，用来支撑「凡是『取第一个』的假设在真实 API 面前都很脆弱」。第 3 课的「一轮可能有多个 tool_use，不能只取第一个」正好是同一条原则的第二次应用，可以直接回指这次经历。
