先记住这三条

1. 缩进代替花括号。块的开头用 :，块的范围由缩进决定。用 4 个空格，不要混用 Tab。

2. 没有变量声明关键字。const / let 一律省掉，直接 x = 1。

3. this 变成显式的 self，而且必须写成方法的第一个参数。

异步

心智模型和 JS 几乎一致，只有一个额外要求：必须有一个入口把事件循环跑起来。Node 里 top-level await 能用，Python 里要显式 asyncio.run()。

import asyncio

async def fetch(n):
    await asyncio.sleep(1)
    return n * 2

async def main():
    # TS: await Promise.all([fetch(1), fetch(2)])
    results = await asyncio.gather(fetch(1), fetch(2))
    print(results)          # [2, 4]

asyncio.run(main())         # ← 入口，忘了写就什么都不会发生

前端迁移者的七个坑

这些不是语法差异，是行为差异。语法差异会报错，行为差异会静默地给出错误结果。

坑 1 · 空列表和空字典是假值

JS 里 if ([]) 成立，Python 里不成立。""、0、None、[]、{}、()、set() 全是假值。好消息：if items: 就是「非空」的地道写法，不用写 len(items) > 0。

坑 2 · 可变默认参数在多次调用间共享 
def add_msg(msg, history=[]):   # ⚠️ 这个 [] 只创建一次！
    history.append(msg)
    return history

add_msg("a")   # ['a']
add_msg("b")   # ['a', 'b'] ← 上次的还在

# 正确写法：
def add_msg(msg, history=None):
    if history is None:
        history = []
坑 3 · is 不是 ===

== 比较值，is 比较是不是同一个对象（相当于 JS 里对象的 ===）。判断相等永远用 ==；is 只用于 None、True、False。"ab" is "ab" 有时为真有时为假，取决于解释器优化，所以别用。

坑 4 · / 永远返回浮点

6 / 3 得到 2.0 而不是 2。整除用 //。注意 // 是向下取整不是截断：-7 // 2 得到 -4，而 JS 的 Math.trunc(-7/2) 是 -3。

坑 5 · 没有块级作用域

作用域的单位是函数，不是花括号。if 或 for 里赋的值，出了块照样能用；循环变量在循环结束后依然存在。这既方便也容易写出意外依赖。

坑 6 · + 不做隐式类型转换

"共 " + 3 直接抛 TypeError，不会得到 "共 3"。要么 f"共 {3}"，要么 "共 " + str(3)。对写惯 JS 的人来说这是好事：错误提前暴露了。

坑 7 · 赋值不复制

b = a 让两个名字指向同一个 list（和 JS 一样）。要副本用 b = a[:]、list(a)，深拷贝用 copy.deepcopy(a)。函数里 append 参数列表，会改到调用方的数据。
